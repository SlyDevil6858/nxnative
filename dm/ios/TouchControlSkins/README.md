# Touch-control skins

Each skin is a folder of individual transparent PNG images, one per control. The launcher validates the full image set before installing it.

- [Default starter artwork](Default/README.md): separate editable SVG source files; export each one to a same-named PNG before importing.
- Built-in controls remain the fallback when no custom skin is installed.

The skin changes only the visual artwork. Native hit-testing, touch ownership, stick movement, button mappings, and the 2D/3D/Tap layout behavior remain handled by NXNative.
